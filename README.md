# 🍕 Pizza Booking App

A simple, responsive pizza ordering web application built using **HTML**, **Bootstrap 5**, **Font Awesome**, and vanilla **JavaScript**. Users can view a pizza menu, fill out a booking form, and see a list of their orders dynamically.

---

## 🚀 Features

- 📋 **Menu Display** – Showcases six popular pizza varieties with images, descriptions, and prices.
- 🛒 **Add to Cart (UI Only)** – "Add to Cart" buttons included for future expansion (not currently functional).
- 📦 **Pizza Booking Form** – Collects customer information and order details.
- 📜 **Order Summary Section** – Displays submitted orders in a list format.
- 💻 **Responsive Design** – Optimized layout for desktop and mobile using Bootstrap.

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the app.
- **CSS/Bootstrap 5** – Styling and responsiveness.
- **Font Awesome** – Icons for UI.
- **JavaScript (ES6)** – Client-side logic for booking and displaying orders.

## 📦 How to Use

1. **Clone or Download** this repository.
2. Open `index.html` in your browser.
3. Browse the menu, fill out the form, and submit your pizza booking.
4. Your orders will appear in the "My Orders" section.
